## 🚀 كيفية الاستخدام

### 1. إضافة حركة لعنصر:
```html
<div class="animate-fade-in-up delay-200">المحتوى</div>
```

### 2. إنشاء كارت تفاعلي:
```html
<div class="interactive-card lift-effect">
    <h3>العنوان</h3>
    <p>المحتوى</p>
</div>
```

### 3. زر بتأثيرات متقدمة:
```html
<button class="btn-interactive ripple-effect glow-effect">
    انقر هنا
</button>
```

### 4. نموذج محسن:
```html
<div class="form-group-interactive">
    <input type="text" class="form-input-interactive">
    <label class="form-label-interactive">الاسم</label>
</div>
```
